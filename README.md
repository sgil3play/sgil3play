## Proyectos

### [CodeQuest](https://github.com/sgil3play/codequest)

Plataforma de practica de codigo para preparar entrevistas tecnicas de backend en Java.
Los retos se ejecutan de verdad: el codigo se compila y se prueba en una JVM aislada, con
limite de tiempo, y el resultado vuelve al navegador caso a caso.

- Backend Spring Boot 3.5.3 con catalogo de retos en YAML (8 katas Java, 20 preguntas
  conceptuales, 6 ejercicios de diseno de sistemas).
- Motor de ejecucion propio: compilacion y ejecucion en un proceso hijo, protocolo de
  linea por stdout y timeout por caso y global.
- Progreso con XP, niveles y racha persistido en JPA/Hibernate sobre H2.
- Frontend Angular 22 con rutas lazy, signals y Markdown sanitizado.
- Docker, docker-compose y pipeline de GitHub Actions.

Por que existe: tras meses fuera del codigo de produccion, el objetivo no era acumular
retos sueltos sino recuperar el ritmo escribiendo Java todos los dias y tener a la vista
los bloques que me faltaban.
